Home page

Technical Description

HTML Structure
The Home page is organised using semantic HTML5 elements to improve readability, accessibility, and search engine optimisation.

  • The <header> element contains the ClimACT logo and the main navigation menu, allowing users to access every page consistently from the top of the website.
  • The <nav> element provides the primary navigation links. An active class is used to highlight the current page.
  • A hero section (<section class="page-hero">) introduces the website with a large heading and a short description of the purpose of ClimACT.
  • The <main> element contains all of the primary page content.
  • Multiple <section> elements divide the page into logical areas including the mission statement and featured content pages.
  • <article> elements are used for the three information cards because each card represents an independent piece of climate-related content.
  • Images include descriptive alt text to support screen readers.
  • The <footer>> contains navigation links, student information, and copyright details that appear consistently across the website.


CSS Techniques
Layout
The page uses a combination of modern CSS layout techniques.
  • CSS Grid is used for the mission card layout (card-grid) so the cards automatically adjust depending on screen size.
  • CSS Grid is also used for the content gallery using:
    • grid-template-columns: repeat(auto-fit, minmax(220px, 1fr))
  • This creates a responsive gallery where images automatically rearrange to fit different screen widths.
  • Flexbox is used within the header and footer to align navigation links and footer columns evenly.
  • Fixed positioning is used for the "Go to Top" button so that it remains visible while scrolling.

Styling
The visual design follows a consistent climate-inspired theme.
  • CSS variables (:root) are used for colours, fonts, spacing, and shadows, making the design easier to maintain.
  • Green colour tones represent sustainability and support the SDG 13 climate action theme.
  • Google Fonts are used to create visual hierarchy:
    • League Spartan for bold headings.
    • Playfair Display for section titles.
    • Montserrat for readable body text.
  • Rounded corners, shadows, and consistent spacing create a modern card-based design.
  • Hover effects scale gallery images and slightly raise cards to improve user interaction.
  • Linear gradients are used behind image captions to improve text readability.


Accessibility

Accessibility was considered by using a clear page structure, meaningful headings, and descriptive alternative text for all images so screen readers can describe them. Keyboard users can navigate interactive elements using visible focus effects, and colour choices provide good contrast to improve readability. Clear navigation and descriptive link text also make the page easier for all users to understand and use.

Gallery Page

Technical Description

HTML Structure
The Gallery page is organised using semantic HTML5 elements to create a clear structure, improve accessibility, and provide a better user experience.

  • The <header> element contains the ClimACT logo and the main navigation menu, allowing users to move between different pages consistently.
  • The <nav> element provides the main website navigation links, with the active class used to highlight the current Gallery page.
  • A hero section (<section class="page-hero">) introduces the Gallery page with a large heading and a short description explaining the purpose of the image collection.
  • The <main> element contains the primary gallery content and separates it from the header and footer sections.
  • The gallery items are organised inside a <div class="thumb-grid"> container, which groups all climate solution images into a structured layout.
  • Each individual image is placed inside a <div class="thumb-card"> element, allowing every gallery item to function as an interactive card.
  • The <img> element is used to display climate-related images, with descriptive alt attributes included to support screen readers and improve accessibility.
  • <h2> and <h3> heading elements are used to organise gallery content into different climate categories such as Carbon Footprints, Renewable Energy, and Community Climate Action.
  • The modal extended view uses <div class="modal-overlay"> and <div class="modal-box"> elements to display additional information without requiring users to leave the page.
  • The <button> element is used for interactive controls, including closing the modal and selecting different colour themes and font styles.
  • The <fieldset> and <legend> elements group related customisation controls, improving structure and accessibility.
  • The <footer> element contains additional navigation links, student information, and copyright details that remain consistent throughout the website.


CSS Techniques
Layout
The Gallery page uses modern CSS layout techniques to create a responsive and interactive image display.
  • CSS Grid is used for the thumbnail gallery layout using:
    • grid-template-columns: repeat(auto-fit, minmax(230px, 1fr))
  • This allows gallery cards to automatically rearrange depending on screen size, providing a responsive layout across desktops, tablets, and mobile devices.
  • Flexbox is used inside the modal controls to align colour theme buttons and font selection options neatly.
  • Fixed positioning is used for the modal overlay and "Go to Top" button so they remain accessible while scrolling through the page.
  • Absolute positioning is used for the modal close button, allowing it to stay positioned in the top-right corner of the popup window.
  • The aspect ratio property is used on gallery images to maintain consistent image proportions and prevent uneven card sizes.

Styling
The visual styling of the Gallery page follows the ClimACT design theme while improving usability and interaction.
  • CSS variables (:root) are used for colours, fonts, spacing, shadows, and border styles to maintain consistency across the website.
  • Blue and green colour tones are used to represent environmental themes and support the climate action concept.
  • Rounded corners and box shadows are applied to gallery cards to create a modern card-based design.
  • Hover effects change the border colour and shadow of gallery cards, providing users with clear feedback that images are interactive.
  • CSS transitions create smooth animations when cards are hovered over and when the modal window appears.
  • Different colour themes such as Forest, Ocean, and Sunset were implemented to allow users to customise the modal appearance.
  • Different font styles were added to improve personalisation and provide users with alternative reading experiences.
  • Overlay backgrounds and gradients are used in the modal design to improve readability and focus attention on the selected image information.



JavaScript Interactivity
The Gallery page uses JavaScript to create an interactive experience without requiring users to navigate away from the page.
  • Event listeners are attached to each gallery thumbnail to detect mouse clicks, keyboard input, and hover events. This allows users to interact with the gallery using either a mouse or keyboard.
  • When a gallery item is selected, JavaScript retrieves the image source, title, description, and alternative text from custom data attributes (data-img, data-title, data-desc, and data-alt). These values are then inserted into the modal window dynamically, allowing a single modal structure to display different content for every gallery item.
  • JavaScript controls the modal popup by adding and removing the is-open CSS class. This displays or hides the extended view without reloading the page, providing a smoother user experience.
  • Hover and keyboard focus effects are enhanced through JavaScript by adding and removing the is-hovered class. This provides immediate visual feedback when users interact with gallery cards.
  • The colour theme buttons use JavaScript to apply different theme classes (theme-forest, theme-ocean, and theme-sunset) to the modal content area. This allows users to personalise the appearance of the extended view./li>
  • Font selection buttons use JavaScript to switch between the default, serif, and monospace font styles by dynamically adding or removing CSS classes from the modal body.
  • Several methods are provided for closing the modal, including clicking the close button, clicking outside the modal window, or pressing the Escape key. These options improve usability and accessibility.


Accessibility

Accessibility was addressed by providing descriptive alternative text for every image, using clear headings to organise the content, and making all gallery items keyboard accessible. Users can open images using the Enter or Space keys, close the pop-up with the Escape key, and navigate using visible focus indicators. The pop-up also includes appropriate accessibility labels, while clear colour contrast and readable fonts improve usability for all users.

Content Page

Technical Description

HTML Structure
The Content page is organised using semantic HTML5 elements to create a structured, accessible, and user-friendly reading experience.

  • The <header> element contains the ClimACT logo and the main navigation menu, allowing users to access other website pages consistently.
  • The <nav> element provides the main website navigation links, helping users move between different sections of the website.
  • A hero section (<section class="page-hero">) introduces the Carbon Footprint content page with a large title and supporting description.
  • The <main> element contains the primary educational content of the page and separates it from the header and footer areas.
  • The <nav class="toc-nav"> element creates an internal table of contents, allowing users to quickly navigate to different sections within the page.
  • Multiple <section class="content-section"> elements are used to divide the information into organised topics such as Transport, Energy, Food, Waste, and Reducing Your Footprint.
  • The <h2> and <h3> heading elements create a clear content hierarchy, making the page easier to read and navigate.
  • The <figure> and <figcaption> elements are used together to display images with supporting descriptions, improving the relationship between visual content and written information.
  • The <img> element is used to display climate-related images, with descriptive alt text included to support screen readers and improve accessibility.
  • The <div class="myth-box"> element highlights common climate misconceptions by separating important information from the main content.
  • The <ul> and <li> elements are used to present climate action points and important facts in an easy-to-read format.
  • The <footer> element contains additional navigation links, student details, and copyright information that are consistent throughout the website.


CSS Techniques
Layout
The Content page uses responsive CSS techniques to create a clear reading layout and improve navigation.
  • CSS Grid is used for the image comparison section (.figure-pair), allowing related content to appear side-by-side on larger screens while automatically adjusting into a single column on smaller devices.
  • Fixed positioning is used for the "Go to Top" button so users can quickly return to the beginning of the page while scrolling through long content.
  • Flexbox is used in shared website components such as the header, navigation, and footer to align elements efficiently.
  • The scroll-margin-top property is used for content sections to ensure internal navigation links correctly position headings below the fixed header.
  • Responsive design techniques are implemented using media queries to improve the layout across different screen sizes.

Styling
The styling of the Content page focuses on readability, consistency, and visual organisation.
  • CSS variables (:root) are used for colours, spacing, shadows, and typography to maintain consistency with the overall ClimACT website design.
  • The climate-inspired colour palette uses green tones and accent colours to reinforce the environmental theme of SDG 13 Climate Action.
  • Section headings use coloured borders and spacing to create clear separation between different topics.
  • Images are styled with borders, rounded corners, and shadows to create a polished presentation while keeping focus on the educational content.
  • The table of contents uses background colour, borders, and spacing to make internal navigation visually distinct and easy to locate.
  • The myth information boxes use highlighted backgrounds and coloured borders to draw attention to important facts and improve content scanning.
  • The "Go to Top" button includes hover and focus effects to provide visual feedback and improve accessibility.
  • Consistent margins, padding, and typography choices improve readability for users viewing long-form educational content.


Accessibility

Accessibility was addressed by using a clear heading structure and a table of contents to help users navigate the page easily. Descriptive alternative text was added to all images, while captions provide additional context. The page also uses readable fonts, good colour contrast, responsive layouts for different screen sizes, and a "Back to Top" button to make navigation easier for both keyboard and screen reader users.

Challenges and Lessons Learned

Maintaining a Consistent Design
One of the biggest challenges was ensuring every page followed the same visual style while still having unique features. This was resolved by creating a shared stylesheet for common components such as the header, navigation, footer, colours, and typography, while using page-specific CSS only for unique layouts and effects. This improved consistency and made the website easier to maintain.


Creating Responsive Layouts
Designing pages that looked good on different screen sizes was challenging. CSS Grid, flexible sizing, and responsive media queries were used so that content automatically adjusted to different devices without breaking the layout. This highlighted the importance of responsive web design from the beginning of development.


Implementing Interactive Features
Developing the interactive gallery required combining CSS animations with JavaScript functionality. Event listeners were used to open and close the image modal, support keyboard controls, and allow users to customise the display. Separating the styling from the JavaScript logic made the code easier to understand and debug.


Improving Accessibility
Making the website accessible required more than adding images and text. Descriptive alternative text, keyboard navigation, visible focus indicators, and clear colour contrast were added to ensure the pages could be used by a wider range of users. This reinforced the importance of designing for accessibility from the start.


Organising Large Amounts of Content
The content pages contained a large amount of information, making them difficult to navigate. A table of contents, clear section headings, and consistent spacing were added to improve readability and allow users to quickly find the information they needed.


Testing and Debugging
During development, issues such as broken image paths, incorrect links, and inconsistent spacing appeared across different pages. These were resolved through regular testing, validation, and careful inspection of the code. This demonstrated the value of testing throughout the development process rather than waiting until the end.


Compliance


The pages were developed in line with key JANET web publishing guidelines by focusing on accessibility, usability, and responsible web design. Semantic HTML was used to create a logical page structure, descriptive alternative text was provided for images, and keyboard-accessible navigation was included where appropriate. Colour choices were selected to provide sufficient contrast, and responsive layouts ensure the pages can be viewed on different devices. Only appropriate, copyright-free or properly attributed images and content were used, and no misleading, offensive, or inappropriate material was included. External links are clearly identified where necessary, and the website does not collect or store personal data beyond the intended feedback form. While the website is a student project rather than a live public service, these practices demonstrate an understanding of JANET's guidance on creating accessible, secure, and responsible web content.
