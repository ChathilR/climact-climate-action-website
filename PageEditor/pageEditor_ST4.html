Profile Page

Technical Description

The User Profile page was built using semantic HTML elements such as main, section, button, and form-related elements to organise the page into clear, well-structured sections. Separate cards were used to display the profile information, progress tracker, and profile image, making the layout easy to understand and navigate.

CSS Flexbox was used to arrange the page layout, while reusable classes provided consistent spacing, colours, borders, and typography. Progress bars, buttons, profile cards, and status indicators were styled with CSS to create a clean and visually consistent interface that matches the rest of the website.

JavaScript was used to provide the page's interactivity. Prompt dialogs collect user information step by step, and DOM manipulation updates the profile details without reloading the page. Functions calculate the completion percentage, update the progress bar, allow users to upload a profile picture, reset the profile, and revisit incomplete steps, creating a dynamic and interactive user experience.

Accessibility

Accessibility was considered throughout the development of the User Profile page. Semantic HTML headings and sections provide a logical page structure for screen readers, while descriptive button labels make the interface easier to understand. Colour choices were selected to provide good contrast between text and backgrounds, improving readability.

Images include meaningful alternative text where appropriate, and the page can be navigated using a keyboard. The profile progress indicator provides clear visual feedback, helping users understand which steps have been completed and which information still needs to be entered.

Sitemap

Technical Description

The Sitemap page was developed using semantic HTML elements such as main, section, and an inline svg element to present the website structure in a clear and organised way. Each page is represented by an SVG node, while connecting lines visually illustrate the relationships between the pages and the overall navigation hierarchy.

CSS was used to style the SVG nodes, connector lines, text, and hover effects while maintaining a consistent appearance with the rest of the website. Flexbox was used to position the main content and ensure the page layout remained clean and responsive across different screen sizes.

Interactivity was achieved by wrapping each SVG node inside an anchor element, allowing users to navigate directly to different pages by clicking the corresponding boxes. Hover and focus effects provide visual feedback, making the sitemap both interactive and easy to use.

Accessibility

Accessibility was considered throughout the Sitemap page by using semantic HTML together with descriptive ARIA labels on the SVG links. This allows screen readers to identify each navigation element and clearly describe its destination to users.

Keyboard users can navigate between all sitemap links using the Tab key, while clear focus and hover styles provide visual feedback. The page also maintains sufficient colour contrast and logical heading levels to improve readability and overall accessibility.

Community Climate Action (Content Page)

Technical Description

The Community Climate Action page was developed using semantic HTML elements such as main, section, article, figure, and nav to organise the content into clear and meaningful sections. A hero section introduces the topic, while an in-page navigation menu allows users to quickly jump to different parts of the page.

CSS was used to create a consistent layout that matches the rest of the website. Responsive images, figure captions, callout boxes, and content sections were styled using reusable classes, while Flexbox and Grid were used where appropriate to improve spacing, alignment, and responsiveness across different screen sizes.

The page also includes internal navigation links, responsive images with descriptive captions, and clearly structured headings to improve readability. Semantic HTML and consistent styling were used throughout the page to provide a clear, informative, and user-friendly learning experience.

Accessibility

Accessibility was considered throughout the page by using a logical heading hierarchy, semantic HTML elements, and descriptive alternative text for all images. The internal navigation menu allows keyboard and screen reader users to quickly move between different sections of the page.

Good colour contrast, readable font sizes, descriptive link text, and responsive layouts improve usability across a wide range of devices. Images include captions to provide additional context, while the page structure makes the content easier to understand for all users.

Challenges and Lessons Learned

One of the main challenges during development was creating an interactive User Profile page while keeping the interface simple and easy to use. Managing the profile progress, updating information dynamically with JavaScript, and allowing users to revisit incomplete steps required careful planning and testing.

Another challenge was ensuring the Sitemap and content page remained consistent with the overall website design. Adjusting layouts, fixing navigation links, and maintaining a uniform appearance across all pages required several revisions and collaboration with other group members.

Throughout this project, I improved my understanding of semantic HTML, CSS layouts, JavaScript DOM manipulation, accessibility, and validation. I also learned the importance of testing pages regularly, validating code, and communicating with the team to ensure all pages worked together correctly.

Compliance

My pages were developed in accordance with JANET web publishing guidelines by using clear, accessible, and well-structured HTML. Semantic elements such as header, main, section, and footer were used to create a logical document structure that improves accessibility and maintainability.

Accessibility was considered throughout the development process. Images include alternative text where appropriate, heading levels follow a logical hierarchy, colour choices provide sufficient contrast, and interactive elements can be accessed using a keyboard. Validation tools were also used to identify and correct HTML issues before submission.

Copyright requirements were respected by using properly licensed resources and acknowledging external sources in the References section. Together, these practices help ensure the website is accessible, maintainable, and compliant with the web publishing standards expected for this coursework.
