Splash Screen

Technical Description

The Splash Screen was developed using semantic HTML elements including header, main, section, and button to create a simple and well-structured introduction to the website. A full-screen background image, website title, mission statement, group member list, and a Skip Intro button were included to provide users with a welcoming first impression.

CSS was used to create the overall layout, full-screen background, loading animation, typography, and responsive positioning of page elements. The design follows the group's colour palette and branding to provide a smooth transition into the Home Page.

JavaScript was used to display the countdown timer that updates every second before automatically redirecting users to the Home Page. The Skip Intro button allows users to bypass the countdown and immediately enter the website, improving usability.

Accessibility

Accessibility was considered throughout the Splash Screen by using a logical heading structure, descriptive alternative text for images, and sufficient colour contrast between text and the background image to improve readability. The Skip Intro button is clearly labelled and easy to identify.

Action Impact Simulator

Technical Description

The Action Impact Simulator was created using semantic HTML elements such as main, section, article, button, and figure. Six action cards were designed to present climate-friendly activities together with images, descriptions, and impact scores in a structured and easy-to-read layout.

Embedded CSS was used to organise the simulator using responsive card layouts, spacing, typography, and visual feedback for selected actions. Additional styling was applied to the impact summary panel, journey image, and background images while maintaining consistency with the website's Global CSS.

JavaScript controls all interactive behaviour on the page. Users can select or remove action cards, calculate their total impact score, receive dynamic feedback, update the impact level, change the journey illustration, switch the page background according to their score, and reset the simulator using the Reset button.

Accessibility

Accessibility was improved by using semantic HTML, descriptive alternative text for all images, readable colour contrast, and clear visual indicators showing selected actions. Interactive controls are clearly labelled to help users understand the simulator.

Content Page (Renewable Energy)

Technical Description

The Renewable Energy Content Page was developed using semantic HTML elements including main, section, figure, nav, and heading elements to organise information into clearly structured sections. Internal navigation links allow users to quickly move between different topics within the page.

Embedded CSS was used to style the table of contents, content sections, images, callout boxes, and the fixed Go to Top button. Images were made responsive and enhanced using borders, spacing, rounded corners, and shadows while maintaining consistency with the website's shared design.

The page uses HTML anchor links for internal navigation and a fixed Go to Top button implemented entirely with HTML and CSS. The content was written specifically for the website and focuses on renewable energy, explaining different energy sources and encouraging users to adopt more sustainable practices.

Accessibility

Accessibility was considered by using semantic HTML, a logical heading hierarchy, descriptive alternative text for every image, readable text, and clear internal navigation. The fixed Go to Top button allows users to easily return to the beginning of the page without using JavaScript.

Challenges and Lessons Learned

One of the main challenges during development was creating an engaging Splash Screen that provided a smooth introduction to the website while meeting all coursework requirements. Implementing the countdown timer, automatic redirect, CSS loading animation, and Skip Intro button required careful testing to ensure they worked together correctly without affecting the user experience.

Developing the Action Impact Simulator was another significant challenge. Implementing the JavaScript logic to calculate impact scores, update the feedback panel, change the journey image, and switch background images dynamically required careful planning and debugging. The Renewable Energy Content Page also required organising a large amount of information into well-structured sections while providing clear internal navigation and maintaining consistency with the shared website design.

Throughout this project, I improved my understanding of semantic HTML, CSS layouts, responsive design, JavaScript event handling, DOM manipulation, accessibility, and HTML validation. I also learned the importance of regular testing, debugging, and collaborating with team members to ensure all pages worked consistently across the website.

Compliance

My pages were developed in accordance with JANET web publishing guidelines by using clear, accessible, and well-structured HTML. Semantic elements such as header, main, section, nav, and footer were used to create a logical document structure that improves accessibility, readability, and maintainability.

Accessibility was considered throughout the Splash Screen, Action Impact Simulator, and Renewable Energy Content Page. Descriptive alternative text was provided for images, heading levels follow a logical hierarchy, colour choices provide sufficient contrast, and interactive elements are clearly labelled. Internal navigation, the fixed "Go to Top" button, and semantic HTML also help improve usability for a wide range of users.

External resources such as royalty-free images and learning materials were used responsibly and acknowledged in the References section where appropriate. All implemented pages were validated using the W3C Nu HTML Checker to identify and correct errors before submission, helping ensure compliance with web standards and coursework requirements.
