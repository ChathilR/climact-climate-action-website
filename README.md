# ClimACT – Climate Action Awareness Website

**Status:** ✅ Completed University Coursework

ClimACT is a multi-page informational website developed as a group coursework project for the **Web Development** module at the **Informatics Institute of Technology (IIT), Sri Lanka**. The project was completed as part of the **BSc (Hons) Computer Science** degree awarded by the **University of Westminster, United Kingdom**.

The website aims to educate users about climate change, promote sustainable living, and encourage positive environmental actions through engaging and interactive web experiences.

> **Project Type:** University Group Coursework (4 Students)  
> **Development Type:** Frontend Web Application (HTML, CSS & JavaScript)  
> **Backend:** None

---

# Project Goals

The primary objectives of ClimACT are to:

- Raise awareness about climate change and environmental sustainability.
- Educate users on the importance of sustainable living.
- Encourage users to adopt eco-friendly habits.
- Provide an engaging and interactive learning experience.
- Demonstrate modern frontend web development using semantic HTML, CSS, and vanilla JavaScript.

# Running the Project

This is a static website built using HTML, CSS, and JavaScript. No installation or external dependencies are required.

## Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open the splash screen or the home page in your preferred web browser.

For the best experience, the project can also be served using any local web server.
