Accessibility Statement

ClimACT has been designed with accessibility in mind to ensure that as many users as possible can access, understand, and navigate the website regardless of their abilities or the device they are using.
We have followed good web development practices and considered accessibility throughout the design and development process.

Accessibility Features

Semantic HTML

The website uses semantic HTML5 elements such as header, navigation, main, section, and footer. This helps screen readers understand the structure of each page and allows users to navigate content more efficiently.

Keyboard Navigation

Interactive elements can be accessed using a keyboard. The Gallery page supports keyboard interaction, allowing users to open gallery items using the Enter or Space keys and close the expanded view using the Escape key.

Alternative Text

Informative images throughout the website include descriptive alternative (alt) text. This allows screen reader users to understand the purpose of images when they cannot be seen.

Responsive Design

The website uses responsive layouts and media queries to ensure that pages adapt to different screen sizes, making the website usable on desktop computers, tablets, and mobile devices.

Colour and Readability

Colours have been selected to provide clear contrast between text and backgrounds. Consistent fonts, spacing, and headings improve readability and make information easier to scan.

Clear Navigation

A consistent navigation menu appears on every page, allowing users to move around the website easily. Internal page links and the "Go to Top" button also help users navigate longer pages quickly.

Accessible Interactive Components

The Gallery page includes an accessible image viewer with keyboard support, focus management, and appropriate ARIA attributes to improve usability for keyboard and assistive technology users.

Accessibility Standards

During development, the website was created with reference to the Web Content Accessibility Guidelines (WCAG) 2.2 Level AA where practical. We also aimed to follow modern HTML5 standards and accessibility best practices throughout the project.

Browser Compatibility

ClimACT has been tested using modern web browsers including Google Chrome and Microsoft Edge. The responsive layout has also been tested across different screen sizes to ensure that content remains readable and functional.
